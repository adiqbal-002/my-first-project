# Finance Management System

A complete starter finance management system using **Flask + SQLite3 + HTML/CSS/JS** covering:

- Module 1: Student registration, fee assignment, fee collection with receipt, student view/edit/delete, filters, reports.
- Module 2: Hostel student registration, daily invoice entry (auto date/month), edit/update/delete invoice, month-wise reports.
- Module 3: Cashbook dashboard combining assigned fees, collected fees, invoice expenses, and running ledger.

## Run

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Visit: `http://127.0.0.1:5000`
